# EDU RACING — Siapa Cepat, Dia Melaju!

Game kuis balapan cepat tepat berbasis tim (2–4 tim) untuk pembelajaran **Bahasa Indonesia Kelas 8 / Fase D — Artikel Ilmiah Populer**.

**Game Design by Dini Christiani** · Guru Bahasa Indonesia · SMP Kristen Petra 5

- Buka di browser (Chrome di Android, Safari di iPad, Chrome/Edge di laptop).
- Pasang ke layar utama tablet ("Tambahkan ke Layar Utama") agar tampil layar penuh dan dapat dimainkan offline.
